Research question

Does an AI formula search find real patterns in stock market data, or would it find equally strong formulas in markets that run backward in time, upside down, or both?

Forge 11 lets a language model, run on the author's own computer, propose formulas that rank the 30 stocks of the Dow Jones Industrial Average using price and volume indicators. Each formula is backtested after trading costs, and the results are fed back so the model can propose better ones.

The experiment runs that identical search five times. Two runs use the real research data; three use versions of the same data that run backward in time, upside down, or both. The model sees the same indicator names in every run and is never told which version it is searching. Each run is measured against its own, equally transformed benchmarks. Afterwards, formulas found in the transformed markets are also tested on the real data. The plan and the hypotheses were committed before any transformed run started.
